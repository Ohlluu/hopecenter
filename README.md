# Lugenia Burns Hope Center — Website Demo

A full demo website for the **Lugenia Burns Hope Center**, a community organizing institution in Bronzeville, Chicago.

Built with Next.js 16, Tailwind CSS, and TypeScript.

---

## Pages

| Page | Route |
|---|---|
| Homepage | `/` |
| About + Victories Timeline | `/about` |
| All 7 Campaigns | `/campaigns` |
| Events with RSVP | `/events` |
| Membership Application | `/membership` |
| Donations | `/donate` |
| News & Blog | `/news` |
| Resources Hub | `/resources` |
| Contact | `/contact` |
| Admin Dashboard | `/admin` |
| Admin → Members | `/admin/members` |
| Admin → Events | `/admin/events` |
| Admin → Donations | `/admin/donations` |
| Admin → Campaigns | `/admin/campaigns` |

---

## Running Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

---

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Styling:** Tailwind CSS
- **Language:** TypeScript
- **Icons:** Lucide React
- **Images:** Unsplash (demo)
